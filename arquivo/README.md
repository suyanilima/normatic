# Arquivo histórico

- `referencias/`: projetos originais e cópias anteriores à unificação.
- `entregas/`: ZIPs de versões anteriores, preservados para consulta ou recuperação.

Esta pasta não é usada pela aplicação e não entra nos novos pacotes. Os documentos e scripts aqui refletem versões anteriores; as instruções atuais estão no README da raiz.

O conteúdo de `referencias/` e `entregas/` é mantido apenas localmente e ignorado pelo Git. Não acompanha novos clones do repositório.
